One line of deadpan weather forecast for Wormholt, a city that does not exist, for make.fun's "Deadpan Forecasts for Cities That Do Not Exist" bounty ($2 in USDC).

> In Wormholt, the sun rises at 6:04 and sets at 6:05, having decided to keep its hours short; a full day of daylight is not expected this week.

## Run it

```sh
python3 main.py
```

Writes the forecast to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
